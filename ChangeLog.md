# Changelog

## Responsive Design
**Change:** Refined the layout using Flexbox, CSS Grid, and media queries to ensure the website displays correctly on mobile (360px), tablet (768px), and desktop (1440px).

**Benefit:** Improved usability across different devices and prevented layout issues such as horizontal scrolling.

---

## Accessibility
**Change:** Used semantic HTML elements (`header`, `nav`, `main`, `section`, `article`, `form`, and `footer`), added descriptive `alt` text for images, and included ARIA attributes for the mobile navigation menu.

**Benefit:** Improved screen reader compatibility, keyboard accessibility, and Lighthouse Accessibility score.

---

## Performance
**Change:** Optimized images, kept the project lightweight by using vanilla HTML, CSS, and JavaScript, and avoided unnecessary libraries.

**Benefit:** Reduced page load time and improved Lighthouse Performance.
